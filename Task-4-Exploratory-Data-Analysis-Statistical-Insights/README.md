
# Task 4: Exploratory Data Analysis & Statistical Insights

## Objective

The objective of this task is to perform Exploratory Data Analysis (EDA) and generate statistical insights from the cleaned retail dataset.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Work Performed

- Loaded the cleaned dataset.
- Checked dataset shape, columns, and missing values.
- Calculated descriptive statistics.
- Calculated mean, median, standard deviation, and quartiles.
- Created histograms for numerical columns.
- Created box plots to identify data distribution and outliers.
- Created a correlation matrix and heatmap.
- Analysed sales based on category and customer segment.
- Tested three business hypotheses.
- Summarised the top five important findings.

## Business Hypotheses

1. Relationship between discount and sales.
2. Relationship between delivery time and returned orders.
3. Spending behaviour of different customer segments.

## Files Included

- `Task_4_EDA_Statistical_Insights.ipynb` – Jupyter Notebook containing complete analysis.
- `clean_dataset.csv` – Cleaned dataset used for analysis.
- `README.md` – Project documentation.

## Conclusion

The project provides useful statistical and business insights from the retail dataset through data analysis and visualisation.
