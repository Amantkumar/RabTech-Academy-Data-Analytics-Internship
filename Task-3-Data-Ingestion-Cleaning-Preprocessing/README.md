
# Task 3: Data Ingestion, Cleaning & Preprocessing with Pandas

## Project Overview
This project focuses on loading, cleaning and preprocessing a real-world e-commerce dataset using Python and Pandas.

## Tasks Performed
- Loaded the raw CSV dataset
- Checked rows, columns and data types
- Handled missing values
- Checked duplicate records
- Corrected incorrect data types
- Detected and handled outliers
- Extracted year and month from date columns
- Created sales and profit-related features
- Exported the cleaned dataset
